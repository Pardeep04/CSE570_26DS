# CSE570 Unit II — Split Learning Package

This package contains three Markdown files, three Google Colab-ready Jupyter notebooks, and one shared CSV dataset.

## Recommended order

1. Part 1: EDA and Visualisation
2. Part 2: Correlation, Outliers, and Feature Engineering
3. Part 3: Imbalanced Data and Preprocessing Pipelines

## Running in Google Colab

1. Upload the `.ipynb` file to Google Colab.
2. Run the import cell.
3. Run the dataset-loading cell.
4. Upload `student_performance_eda.csv` when prompted.
5. Continue running the remaining cells from top to bottom.
